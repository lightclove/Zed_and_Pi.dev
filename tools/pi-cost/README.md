# pi-cost

Отчёт по токенам и деньгам для сессий pi (JSONL-файлы).

## Запуск

```bash
node tools/pi-cost/pi-cost.mjs                       # все сессии (~/.pi/agent/sessions, рекурсивно)
node tools/pi-cost/pi-cost.mjs session.jsonl         # один файл
node tools/pi-cost/pi-cost.mjs dir1 dir2 --json      # папки + машинный вывод (JSON)
```

## Семантика

- Каждая ассистентская запись = один оплаченный API-вызов → суммируются **все** записи
  (включая заброшенные ветки): это реальный расход, а не только активная ветка.
- `hit%` = `cacheRead / (input + cacheRead)` — доля входных токенов, взятых из кэша провайдера.
- `reasoning` — подмножество `output` (мыслительные токены, тоже тарифицируются как output).
- `cost` — сумма `usage.cost.total` (считается pi по ценам каталога). Вызовы без `usage` пропускаются.

## Ограничения

- Схема привязана к формату сессий pi 1.x (`message.usage.*`). При обновлении pi сверяй итоги
  с командой `/session` внутри pi и правь парсер при расхождении.
- Файлы, где `usage` отсутствует (например, у провайдеров без отчёта о токенах), не учитываются.
