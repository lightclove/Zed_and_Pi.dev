# CI/CD с GitHub Actions (универсально)

Переиспользуемый харнесс: `templates/github-actions/` (в этом репозитории).
Полная справка, модель безопасности и числа: `references/github-actions.md`.

## Правила

1. **CI — самый дешёвый детектор ошибок** (H1). lint/typecheck/test на каждом push и PR —
   до того, как сбой увидит человек или агент. Проект без CI переносит обнаружение ошибок
   на время ревью — самую дорогую точку.
2. **Дёшево раньше дорогого** (H1). Порядок: secret scan → lint → typecheck → test → build.
   Дорогие джобы гейтятся дешёвыми: красный lint убивает тест-прогон до того, как тот
   потратит минуты. lint и typecheck идут параллельно после secret scan.
3. **Минимально достаточный CI** (A13/YAGNI). Старт — универсальный шаблон с командами,
   которые у проекта реально есть. Пустая команда = пропущенная джоба. Матрицу, coverage,
   CodeQL добавлять только по измеренной потребности.
4. **CI сборки/тестов не нужны секреты.** Канонический пайплайн не использует ни одного
   credentials. Секреты появляются только на деплое/публикации — и там через OIDC,
   никогда долгоживущие токены (справка, раздел «Модель безопасности»).
5. **Кэш и отмена — по умолчанию, минуты — по числам** (A1). Кэш зависимостей +
   `concurrency.cancel-in-progress` дают быстрый фидбек без лишних минут. Прежде чем
   оптимизировать дальше — измерить время прогона.
6. **Контракт до кода** (H3). Входы `reusable-ci.yml` — это контракт: проект декларирует
   язык и команды, пайплайн остаётся каноническим и проверенным. Форк пайплайна под
   проект — ошибка: исправления перестают распространяться.
7. **Сбой — громко, никогда не «успех»** (A2). Каждая джоба падает с ненулевым кодом;
   никаких `|| true`, `continue-on-error` для проверок. Отмена/таймаут — это сбой,
   а не пропуск.
8. **Пинить сторонние экшены.** `actions/*` — мажорным тегом (`@v7`); для
   security-sensitive репозиториев — SHA с комментарием. Никогда `@main`/`@master`
   стороннего экшена.

## Чек-лист: подключить CI к проекту

- [ ] Запустить scaffolder: `node templates/github-actions/scaffold-ci.mjs <target-dir>`
      (язык определяется по манифестам; при расхождении — `--lang`).
- [ ] `.github/workflows/ci.yml` декларирует реальные команды проекта (не дефолты вслепую).
- [ ] Локально зелёные lint + typecheck + test **до** пуша — CI не место первого запуска (H1).
- [ ] gitleaks-скан работает (эшелон в дополнение к pre-commit-гейту этого харнесса).
- [ ] `permissions: contents: read`; в настройках репозитория нет секретов.
- [ ] Первый прогон просмотрен целиком; красные джобы починены, а не выключены.

## Чек-лист: менять CI существующего проекта

- [ ] Меняется только `ci.yml` (контракт), не `reusable-ci.yml`.
- [ ] Новая команда сначала зелёная локально, потом в CI.
- [ ] Секреты не появляются: новая джоба не тянет credentials; для деплоя — OIDC.
- [ ] Новый сторонний экшен запинен тегом/SHA и проверен его README.
